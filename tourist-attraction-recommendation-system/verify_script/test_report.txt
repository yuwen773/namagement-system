================================================================================
                    API 端点清单
================================================================================

1. POST /api/accounts/register/
   - 功能: 用户注册
   - 认证: 不需要
   - 请求参数: username, password, password_confirm, real_name, phone, email
   - 成功响应: 201 Created
   - 错误响应: 400 Bad Request

2. POST /api/accounts/login/
   - 功能: 用户登录
   - 认证: 不需要
   - 请求参数: username, password
   - 成功响应: 200 OK (包含 access_token 和 refresh_token)
   - 错误响应: 400 Bad Request

3. GET /api/accounts/profile/
   - 功能: 获取个人信息
   - 认证: 需要 (Bearer Token)
   - 成功响应: 200 OK
   - 错误响应: 401 Unauthorized

4. PUT /api/accounts/profile/
   - 功能: 更新个人信息
   - 认证: 需要 (Bearer Token)
   - 请求参数: real_name, phone, email (可选)
   - 成功响应: 200 OK
   - 错误响应: 400 Bad Request, 401 Unauthorized

5. POST /api/accounts/change-password/
   - 功能: 修改密码
   - 认证: 需要 (Bearer Token)
   - 请求参数: old_password, new_password, new_password_confirm
   - 成功响应: 200 OK
   - 错误响应: 400 Bad Request, 401 Unauthorized

6. POST /api/accounts/token/refresh/
   - 功能: 刷新访问令牌
   - 认证: 不需要 (需要 refresh_token)
   - 请求参数: refresh
   - 成功响应: 200 OK (包含新的 access_token)
   - 错误响应: 401 Unauthorized

7. DELETE /api/accounts/delete-account/
   - 功能: 注销账号
   - 认证: 需要 (Bearer Token)
   - 成功响应: 200 OK
   - 错误响应: 401 Unauthorized

                    改进建议
================================================================================

1. 响应格式一致性
   - TokenRefreshView 使用标准JWT响应格式，与其他接口的自定义格式不一致
   - 建议: 统一所有接口的响应格式为 { code: 0, data: {...} }

2. 安全增强
   - 建议添加请求频率限制防止暴力破解
   - 建议添加密码强度验证（大小写、数字、特殊字符）
   - 建议添加登录失败次数限制
   - 建议添加邮箱验证功能

3. 用户体验
   - 建议在响应中添加更多有用的错误信息
