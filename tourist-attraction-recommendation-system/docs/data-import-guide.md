# 景点数据导入指南

**文档版本:** v1.0
**创建日期:** 2026-02-12
**适用系统:** 旅游景点推荐系统

---

## 一、概述

本指南描述如何将外部数据集导入到旅游景点推荐系统中。系统支持从 Excel 文件导入景点数据，包含自动清洗、去重、分类等功能。

### 1.1 支持的数据集

| 数据集 | 文件名 | 记录数 | 主要用途 |
|--------|--------|--------|----------|
| 数据集1 | 全国5A级景区.xlsx | 247 条 | 权威5A级景区信息 |
| 数据集2 | 全国旅游景点及描述.xls | 3,526 条 | 完整景点信息（含描述、评论等） |

### 1.2 数据来源

- **数据集1**: 国家旅游局官方认证的5A级景区
- **数据集2**: 包含用户评论、攻略信息的综合景点数据

## 三、命令详解

### 3.1 import_attractions - 数据导入命令

#### 基本用法

```bash
# 导入所有数据集
python manage.py import_attractions

# 先清空再导入
python manage.py import_attractions --clear

# 只导入特定数据集
python manage.py import_attractions --file dataset2  # 只导入数据集2
python manage.py import_attractions --file dataset1  # 只导入5A级景区

# 试运行（不写入数据库）
python manage.py import_attractions --dry-run

# 自定义批次大小
python manage.py import_attractions --batch-size 1000
```

#### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `--file` | choice | all | 选择导入的数据集 |
| `--clear` | flag | False | 导入前清空现有数据 |
| `--dry-run` | flag | False | 试运行模式 |
| `--batch-size` | int | 500 | 批量写入的批次大小 |

## 四、数据模型扩展

### 4.1 新增字段

为支持数据集导入，`Attraction` 模型新增了以下字段：

```python
class Attraction(models.Model):
    # ... 原有字段 ...

    # 新增字段
    latitude = models.FloatField('纬度', null=True, blank=True)
    longitude = models.FloatField('经度', null=True, blank=True)
    rating_percentage = models.FloatField('好评率', default=0.0)
    guide_count = models.IntegerField('攻略数量', default=0)
    ranking = models.IntegerField('城市排名', null=True, blank=True)
    level = models.CharField('景区等级', max_length=10, blank=True)
```

### 4.2 字段说明

| 字段 | 类型 | 来源数据集 | 说明 |
|------|------|------------|------|
| `latitude` | Float | 2 | 地理坐标纬度 |
| `longitude` | Float | 2 | 地理坐标经度 |
| `rating_percentage` | Float | 2 | 好评率（0-100） |
| `guide_count` | Integer | 2 | 攻略数量 |
| `ranking` | Integer | 2 | 城市内排名 |
| `level` | CharField | 1 | 景区等级（5A/4A等） |

### 5.2 字段映射

#### 数据集2 映射规则

| 源字段 | 目标字段 | 转换规则 |
|--------|----------|----------|
| 景点名 | name | 去除首尾空格 |
| 简介 | description | 去除首尾空格 |
| 地名 + 景点名 | address | 字符串拼接 |
| 地名 | region | 直接映射 |
| 评论人数 | view_count | 转换为整数 |
| 攻略数量 | guide_count | 转换为整数 |
| 排名 | ranking | 转换为整数 |
| 星级 | rating_percentage | `'94%'` → `94.0` |
| 经度 | longitude | 转换为浮点数 |
| 纬度 | latitude | 转换为浮点数 |

#### 数据集1 映射规则

| 源字段 | 目标字段 | 转换规则 |
|--------|----------|----------|
| dth_title | name | 去除首尾空格 |
| Province | region | 直接映射 |
| bd_lon/gg_lon | longitude | 优先百度坐标 |
| bd_lat/gg_lat | latitude | 优先百度坐标 |
| level | level | 固定值 `'5A'` |

### 5.3 去重策略

- **去重依据**: 景点名称（name）
- **保留规则**: 保留第一条出现的记录
- **后续处理**: 数据集1会更新已存在的5A级景区记录

## 七、常见问题

### Q1: 导入时提示 "文件不存在"

**原因**: 数据文件路径错误

**解决方案**:
```bash
# 确认数据文件位置
ls data/

# 如果文件在其他位置，使用软链接
ln -s /path/to/data ./data
```

### Q2: 中文字符显示乱码

**原因**: 系统编码问题

**解决方案**:
```bash
# Windows
chcp 65001
python manage.py import_attractions
```

### Q3: 内存不足错误

**原因**: 数据量过大导致内存溢出

**解决方案**:
```bash
# 减小批次大小
python manage.py import_attractions --batch-size 200
```

### Q4: 分类不准确

**原因**: 自动分类规则有限

**解决方案**:
1. 手动更新分类：`Attraction.objects.filter(name='xxx').update(category='xxx')`
2. 添加新的关键词规则到 `data_cleaner.py`

### Q5: 如何添加新的数据集

1. 在 `data_cleaner.py` 中添加新的清洗方法
2. 在 `import_attractions.py` 中添加导入逻辑
3. 测试验证

## 八、性能优化

### 8.1 批量导入优化

- 使用 `bulk_create` 批量写入
- 默认批次大小: 500
- 可根据服务器性能调整 `--batch-size`

### 8.2 数据库索引

系统自动为以下字段建立索引：
- `name` - 景点名称
- `category` - 分类
- `region` - 地区
- `view_count` - 浏览量
