## 四、综合可用性评估

### 4.1 数据集对比分析

| 评估维度 | 数据集1 (5A级景区) | 数据集2 (旅游景点描述) |
|----------|-------------------|----------------------|
| 数据量 | 247 条 | 3,526 条 |
| 权威性 | 高（官方5A认证） | 中（用户生成内容） |
| 信息完整度 | 低（缺少描述） | 高（包含简介） |
| 用户互动数据 | 无 | 有（评论、攻略） |
| 地理信息 | 完整（双坐标系） | 完整（经纬度） |
| 地址粒度 | 省级 | 市级 |
| 可直接使用 | 需要补充大量字段 | 部分字段可用 |

### 4.2 推荐使用方案

#### 方案A：以数据集2为主（推荐）

**理由:**
1. 数据量更大（3,526 vs 247）
2. 包含景点简介（description），这是核心展示内容
3. 有用户互动数据，可直接用于热度计算
4. 有好评率，可用于推荐算法

**需要转换的字段:**
- `星级`：从"94%"转换为数值 0-5 或 0-10
- `地名` + `景点名` 组合成 `address`
- 根据地名推断 `category`（可建立映射表）
- 缺失字段设默认值

#### 方案B：数据集1作为补充

**用途:**
1. 作为"5A级景区"的特色分类
2. 提供更准确的省级地区信息
3. 利用双坐标系统优化地图功能

### 5.3 数据导入示例

```sql
-- 建议的字段映射
INSERT INTO attractions (
    name,              -- 景点名
    description,       -- 简介
    address,           -- CONCAT(地名, ' ', 景点名)
    category,          -- 需要建立地名->类别的映射表
    region,            -- 地名（城市）
    opening_hours,     -- 默认'全天开放'或待补充
    cover_image,       -- 待补充
    images,            -- 空数组[]
    view_count,        -- 评论人数
    longitude,         -- 经度
    latitude           -- 纬度
)
SELECT
    `景点名`,
    `简介`,
    CONCAT(`地名`, ' ', `景点名`) as address,
    CASE
        WHEN `地名` IN ('北京', '西安', '南京') THEN '人文古迹'
        WHEN `地名` IN ('张家界', '桂林', '九寨沟') THEN '自然风光'
        WHEN `景点名` LIKE '%迪士尼%' OR `景点名` LIKE '%乐园%' THEN '主题乐园'
        ELSE '其他'
    END as category,
    `地名` as region,
    '全天开放' as opening_hours,
    '' as cover_image,
    '[]' as images,
    `评论人数` as view_count,
    `经度` as longitude,
    `纬度` as latitude
FROM tourist_attractions_raw;
```

### 6.2 完整模型定义

```python
from django.db import models

class Attraction(models.Model):
    """景点模型"""

    # 基础信息
    name = models.CharField('景点名称', max_length=200)
    description = models.TextField('景点描述')
    address = models.CharField('详细地址', max_length=500)

    # 分类信息
    CATEGORY_CHOICES = [
        ('人文古迹', '人文古迹'),
        ('自然风光', '自然风光'),
        ('主题乐园', '主题乐园'),
        ('现代建筑', '现代建筑'),
        ('其他', '其他'),
    ]
    category = models.CharField('景点类别', max_length=20, choices=CATEGORY_CHOICES)
    region = models.CharField('所属地区', max_length=100)  # 城市或省份

    # 运营信息
    opening_hours = models.CharField('开放时间', max_length=200, blank=True)

    # 媒体资源
    cover_image = models.URLField('封面图片', max_length=500, blank=True)
    images = models.JSONField('图片列表', default=list, blank=True)

    # 统计数据
    view_count = models.IntegerField('浏览量', default=0)
    rating_percentage = models.FloatField('好评率', default=0.0)
    guide_count = models.IntegerField('攻略数量', default=0)
    ranking = models.IntegerField('城市排名', null=True, blank=True)

    # 地理坐标
    latitude = models.FloatField('纬度', null=True, blank=True)
    longitude = models.FloatField('经度', null=True, blank=True)

    # 官方评级
    level = models.CharField('景区等级', max_length=10, blank=True)  # 5A, 4A, 3A等

    # 时间戳
    created_at = models.DateTimeField('创建时间', auto_now_add=True)
    updated_at = models.DateTimeField('更新时间', auto_now=True)

    class Meta:
        db_table = 'attractions'
        verbose_name = '景点'
        verbose_name_plural = '景点'
        ordering = ['-view_count']

    def __str__(self):
        return self.name
```

## 七、最终结论与建议

### 7.1 可用性评级

| 数据集 | 可用性 | 推荐程度 | 说明 |
|--------|--------|----------|------|
| **数据集1：5A级景区** | 需要转换 | 辅助使用 | 权威性高但缺少描述信息 |
| **数据集2：旅游景点描述** | 部分可用 | ⭐ **主要使用** | 数据完整，包含核心展示内容 |

### 7.2 总体建议

1. **优先使用数据集2**
   - 3,526 条景点记录，数量充足
   - 包含景点简介、评论数据，可直接支持核心功能
   - 有好评率和攻略数量，可用于推荐算法

2. **补充缺失字段**
   - `category`：建立地名到类别的映射规则
   - `opening_hours`：使用默认值或从 API 获取
   - `cover_image/images`：使用爬虫获取或使用占位图

3. **数据集1作为特色数据**
   - 可将 5A 级景区作为精选分类展示
   - 用于权威认证标识

4. **扩展模型**
   - 建议添加经纬度、好评率、攻略数量等字段
   - 充分利用数据集价值，支持更丰富的功能

### 7.3 数据导入优先级

```
高优先级：数据集2（全国旅游景点及描述）
  ├─ 包含景点名称、简介、评论数据
  ├─ 可直接支持核心功能（浏览、搜索、推荐）
  └─ 导入后系统即可正常运行

中优先级：数据集1（5A级景区）
  ├─ 作为 5A 级特色分类
  ├─ 提供省级地区粒度
  └─ 提供双坐标系统支持
```

### 7.4 注意事项

1. **坐标系统统一**
   - 数据集1 使用百度/高德坐标系
   - 数据集2 使用标准经纬度
   - 需要统一为 WGS-84 或 GCJ-02 坐标系

2. **数据格式转换**
   - 星级格式需要转换（百分比字符串 -> 数值）
   - 地理信息需要清洗和验证

3. **分类信息建立**
   - 需要人工或规则建立地名到类别的映射
   - 可基于地名或景点名关键词进行智能分类

4. **图片资源获取**
   - 数据集中不包含图片
   - 需要通过爬虫或 API 获取
   - 初期可使用占位图

5. **数据清洗**
   - 建议在导入前进行数据清洗
   - 去除重复记录
   - 验证地理坐标准确性
