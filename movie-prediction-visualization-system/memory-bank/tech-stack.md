# 技术栈 (Tech Stack)

## 后端 (Backend)
*   **开发语言**: Python 3.11+
*   **Web 框架**: Django 5.2
*   **API 框架**: Django REST Framework (DRF)
*   **数据库**: MySQL 8.0+
*   **数据分析**: Pandas, NumPy, Scikit-learn

## 前端 (Frontend)
*   **核心框架**: Vue 3 + Vite
*   **UI 组件库**: Element Plus
*   **数据可视化**: Apache ECharts
*   **样式框架**: Tailwind CSS
*   **状态管理**: Pinia
