# 电影票房预测与可视化系统 - 产品需求文档 (PRD)

## 1. 文档概述
### 1.1 项目背景
本项目旨在构建一个基于Python的电影票房预测与可视化系统。通过收集和管理影片、影院及票房数据，利用数据可视化技术展示市场趋势，并采用基础算法模型对未来票房进行预测，为用户提供直观的数据参考，为管理员提供高效的数据管理工具。

### 1.2 用户角色
系统包含两个主要角色：
1.  **管理员 (Administrator)**: 负责系统基础数据的维护（影片、影院、票房录入）、用户管理以及预测模型的监控。
2.  **普通用户 (User)**: 浏览票房数据、查看可视化报表、使用票房预测功能、管理个人信息。

---

## 2. 功能架构与页面规划
> 注：登录/注册页面为公共基础页面，不计入核心功能页面数量统计。

### 2.1 管理端 (Administrator) - 共 6 个核心页面

#### 页面 1: 系统概览 (Dashboard)
*   **功能描述**: 管理员登录后的首屏，展示系统整体运行状态。
*   **核心模块**:
    *   **关键指标卡片**: 展示影片总数、入驻影院数、累计票房总额、注册用户数。
    *   **快捷入口**: 快速跳转至“录入票房”、“添加影片”等高频操作。
    *   **最新数据预览**: 展示最近录入的5条票房记录。

#### 页面 2: 影片与类型管理 (Movie Management)
*   **功能描述**: 集中管理电影的基础信息及其分类。
*   **核心模块**:
    *   **影片列表**: 展示影片名称、导演、主演、上映时间、类型等列。支持按名称搜索。
    *   **影片CRUD**: 新增影片、编辑影片详情、删除影片。
    *   **类型维护 (Tab/弹窗)**: 管理影片类型（如动作、科幻），支持类型的增删改，确保数据分类规范。

#### 页面 3: 院线与地域管理 (Cinema & Region Management)
*   **功能描述**: 管理票房来源的基础设施数据。
*   **核心模块**:
    *   **影院管理**: 列表展示影院名称、地址、联系方式。支持增删改查。
    *   **地域管理**: 维护省份/城市/区域信息，作为票房统计的地理维度（如：北京、上海、广东）。

#### 页面 4: 票房数据录入 (Box Office Data)
*   **功能描述**: 系统核心数据的录入与维护中心。
*   **核心模块**:
    *   **数据列表**: 按日期展示各影片的当日票房、排片场次、观影人次。
    *   **数据录入**: 管理员手动录入每日票房数据（选择影片 -> 选择日期 -> 输入金额）。
    *   **数据修正**: 对录入错误的历史票房数据进行修改或删除。

#### 页面 5: 趋势预测分析 (Prediction Analysis)
*   **功能描述**: 展示基于历史数据的预测结果，并进行对比验证。
*   **核心模块**:
    *   **预测概览**: 展示系统计算出的未来一周/一月票房趋势图（折线图）。
    *   **实测对比**: 将“预测票房”与“实际票房”在同一图表中叠加显示，验证算法准确性。
    *   **算法说明**: 简单说明当前使用的计算逻辑（如线性回归趋势线）。

#### 页面 6: 用户权限管理 (User Management)
*   **功能描述**: 管理系统的注册用户。
*   **核心模块**:
    *   **用户列表**: 查看所有注册用户的基本信息（用户名、注册时间、状态）。
    *   **权限控制**: 禁用违规账号、重置用户密码、删除恶意用户。

### 2.2 用户端 (User) - 共 5 个核心页面

#### 页面 1: 数据看板首页 (Home Dashboard)
*   **功能描述**: 用户进入系统的第一视窗，聚合最核心的市场数据。
*   **核心模块**:
    *   **票房总榜 (Top 10)**: 展示历史票房最高的10部电影排名。
    *   **仪表盘**: 展示今日大盘总票房、本周票房冠军。
    *   **类型占比预览**: 一个简化的饼图，展示当前市场最受欢迎的电影类型分布。

#### 页面 2: 票房查询中心 (Data Query)
*   **功能描述**: 提供详细的历史票房数据检索功能。
*   **核心模块**:
    *   **筛选栏**: 支持按“时间范围”、“影片名称”、“地区”进行组合搜索。
    *   **数据表格**: 详细列出符合条件的票房记录，支持按票房金额排序。

#### 页面 3: 可视化图表库 (Visualization Gallery)
*   **功能描述**: 深度数据分析页面，包含多种图表视图。
*   **核心模块**:
    *   **地域分布图 (柱状图)**: 展示不同地区（如各省份）的票房贡献对比。
    *   **类型偏好图 (饼图/环形图)**: 详细展示动作、爱情、科幻等类型的市场份额。
    *   **时间走势图 (折线图)**: 展示大盘票房随日/周/月的变化曲线，体现周期性。

#### 页面 4: 未来票房预测 (Future Prediction)
*   **功能描述**: 用户选择特定影片，查看系统对其未来票房的预估。
*   **核心模块**:
    *   **影片选择器**: 用户下拉选择正在上映或即将上映的影片。
    *   **预测结果图**: 展示该影片未来 7-30 天的票房走势预测曲线。
    *   **趋势结论**: 给出简单的文字结论（如：“该影片处于上升期”或“热度逐渐下降”）。

#### 页面 5: 个人中心 (Profile)
*   **功能描述**: 用户个人信息的自我维护。
*   **核心模块**:
    *   **基本资料**: 修改昵称、联系电话、邮箱。
    *   **安全设置**: 修改登录密码。

## 3. 核心业务逻辑与算法

### 3.1 票房趋势预测算法 (Simple Calculation)
为满足“通过简单计算体现未来趋势”的要求，系统将采用 **线性回归 (Linear Regression)** 或 **移动平均法 (Moving Average)**。

*   **算法逻辑**:
    1.  **数据清洗**: 提取某部影片过去 $N$ 天的单日票房数据 $(x_1, y_1), (x_2, y_2), ..., (x_n, y_n)$，其中 $x$ 为时间，$y$ 为票房。
    2.  **模型计算**:
        *   利用最小二乘法拟合一条直线 $y = kx + b$。
        *   或者计算最近 3 天的加权平均值作为下一天的预测值：$P_{next} = (y_n * 0.5 + y_{n-1} * 0.3 + y_{n-2} * 0.2)$。
    3.  **结果输出**: 根据计算出的公式，生成未来 5-7 天的预测数值。
    4.  **可视化**: 将历史数据点（实线）与预测数据点（虚线）绘制在同一坐标系中。

### 3.2 数据可视化逻辑
*   **Echarts/Matplotlib集成**: 前端使用图表库接收后端传递的 JSON 数据进行渲染。
*   **Top 10 统计**: SQL 层面直接聚合 `SUM(box_office) GROUP BY movie_id ORDER BY total DESC LIMIT 10`。
*   **类型占比**: SQL 层面聚合 `COUNT(*)` 或 `SUM(box_office) GROUP BY movie_type`。

## 4. 非功能需求
1.  **开发测试便捷性**: 用户密码无需加密。
2.  **响应速度**: 图表加载时间不超过 2 秒。
