# 电影票房预测与可视化系统 - 实施计划

## 实施原则

1. **前后端分离开发**：先完成所有后端模块，生成完整接口文档后，再启动前端开发
2. **小步迭代验证**：每个步骤完成后立即测试验证
3. **不重复造轮子**：优先使用成熟的第三方库和框架
4. **中文命名规范**：数据库字段和业务逻辑使用中文命名
5. **前端设计规范**：所有前端页面必须使用 `frontend-design` skill 进行设计，确保界面高质量、美观且避免通用 AI 审美

## 步骤 2.6：预测算法模块

   - numpy
   - scikit-learn
2. 安装依赖后，在 `prediction/services.py` 创建预测服务：
   - `get_movie_history` - 获取影片历史票房数据
   - `linear_regression_predict` - 线性回归预测
   - `moving_average_predict` - 移动平均预测
3. 预测算法逻辑：
   - 输入：影片 ID，预测天数
   - 处理：获取该影片过去 N 天的票房数据，进行计算
   - 输出：未来 N 天的预测值数组
4. 在 `prediction/views.py` 创建：
   - 获取影片预测数据接口（`/api/prediction/movie/{id}/`）
   - 获取预测对比数据（历史+预测）
5. 在 `prediction/serializers.py` 创建预测结果序列化器
