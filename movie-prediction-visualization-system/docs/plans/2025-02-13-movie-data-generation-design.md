# 电影数据批量生成设计方案

## 项目概述

为电影票房预测与可视化系统生成5000+部电影及相关数据，确保预测功能可用。

## 数据规模

| 数据类型 | 数量 | 说明 |
|---------|------|------|
| 电影 | 5000+部 | 2025-2026年上映 |
| 影院 | 50-100家 | 覆盖主要城市 |
| 票房记录 | 约100万+条 | 每电影约200条 |

## 数据结构

### 1. 电影模型 (Movie)

| 字段 | 类型 | 说明 |
|-----|------|------|
| title | CharField | 电影名称（中文） |
| director | CharField | 导演 |
| actors | CharField | 主演（逗号分隔） |
| release_date | DateField | 上映时间 |
| duration | IntegerField | 片长（分钟） |
| type | ForeignKey | 影片类型 |
| box_office_total | DecimalField | 累计票房（万元） |
| status | CharField | 状态：RELEASED/COMING |

### 2. 影院模型 (Cinema)

| 字段 | 类型 | 说明 |
|-----|------|------|
| name | CharField | 影院名称 |
| region | ForeignKey | 所属区域 |
| address | CharField | 地址 |
| screen_count | IntegerField | 屏幕数量 |
| seats_count | IntegerField | 座位数量 |

### 3. 票房记录模型 (BoxOfficeRecord)

| 字段 | 类型 | 说明 |
|-----|------|------|
| movie | ForeignKey | 影片 |
| cinema | ForeignKey | 影院 |
| record_date | DateField | 记录日期 |
| daily_box_office | DecimalField | 当日票房（元） |
| screening_count | IntegerField | 排片场次 |
| audience_count | IntegerField | 观影人次 |

## 生成规则

### 电影数据

- **上映时间**：2025年1月 - 2026年12月均匀分布
- **类型分布**：
  - 动作 20%
  - 喜剧 18%
  - 爱情 15%
  - 科幻 12%
  - 悬疑 10%
  - 恐怖 8%
  - 动画 7%
  - 其他 10%
- **片长**：60-180分钟，根据类型差异化分布
- **票房**：根据类型、上映时段、热度指数生成合理区间

### 票房数据

- **预热期**：上映前30-60天生成预售/热度数据
- **上映期**：上映后30-90天高票房，逐日衰减
- **衰减规律**：每周约15%衰减，周末1.5倍
- **数据时间范围**：2024年12月 - 2026年12月

### 影院数据

- **数量**：80家（取中间值50-100）
- **分布**：覆盖北京、上海、广州、深圳、成都、杭州等主要城市
- **规模**：每影院3-10个屏幕，100-500座位

## 预测功能保障

- 每部电影有足够历史数据
- 上映前30-60天预热数据
- 上映后30-90天票房走势数据
- 支持7天/30天预测

## 实施步骤

1. 创建数据生成management command
2. 生成影院数据（50-100家）
3. 生成电影数据（5000+部）
4. 生成票房记录（100万+条）
5. 验证数据完整性和预测功能

## 预计执行时间

- 影院生成：秒级
- 电影生成：约1-2分钟
- 票房生成：约5-10分钟（批量处理）
