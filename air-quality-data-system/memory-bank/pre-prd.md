## 基于python全国空气质量的数据与居民个人防护指南的可视化研究

本课题旨在设计并实现一个基于B/S架构的国家级空气质量监测与居民防护指导平台。核心目的是构建完整的空气质量数据处理与可视化流程，通过Python技术获取全国污染物数据，分析时空分布规律，并将分析结果转化为直观的可视化信息和个性化防护指南，为公众提供科学的健康防护决策支持。
设计任务：
1.根据自身情况，选用Windows为操作系统
2.选择VMware Workstation虚拟机
3.完成软件开发环境配置
4.确定系统任务与功能模块
5.程序的设计与应用开发
6.参数功能的调试与实现
7.系统的修正与完善
主要研究内容及基本要求
1.研究内容
1）空气质量数据处理与分析：研究多源空气质量数据的采集、清洗与预处理方法，分析污染物时空分布规律及特征差异。
2）可视化系统设计与实现：采用前后端分离架构（Django REST Framework + Vue 3），利用ECharts实现空气质量数据的多维度交互式展示与探索。
3）防护指南生成模型：研究基于规则的决策树模型，将空气质量数据转化为个性化的居民防护建议。
2.基本要求：
1）了解我国空气质量监测体系及公众健康防护需求
2）掌握Python数据处理与可视化技术栈
3）熟悉Django Web开发框架（DRF）及Vue 3前端技术
4）具备API数据采集与数据库管理能力
5）掌握数据清洗、分析与可视化方法
6）具备系统集成与测试能力
7）具备良好的数据分析与问题解决能
