# 反馈功能设计文档

**日期**: 2026-02-28
**状态**: 已批准

---

## 需求概述

- **功能**: 用户向管理员反馈问题/建议
- **内容**: 纯文本描述 + 联系方式（可选）
- **权限**: 需登录后才能提交
- **处理**: 管理员可查看、标记处理状态、删除

---

## 数据模型

### Feedback

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user | FK(User) | 提交用户 |
| title | Char(200) | 反馈标题 |
| content | Text | 反馈内容 |
| contact | Char(100) | 联系方式（可选）|
| status | Char(20) | pending(默认) / processed |
| created_at | DateTime | 提交时间 |

---

## API 设计

### 用户端

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/feedback/ | 提交反馈 |
| GET | /api/feedback/my/ | 查看我的反馈列表 |

### 管理端

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/feedback/ | 查看全部反馈列表（支持状态筛选）|
| PATCH | /api/feedback/{id}/ | 更新反馈状态 |
| DELETE | /api/feedback/{id}/ | 删除反馈 |

### Response Format

```json
// 成功
{ "code": 0, "data": {...}, "total": n }

// 失败
{ "code": -1, "message": "错误描述" }
```

---

## 权限设计

- 用户: 只能提交和查看自己的反馈
- 管理员: 可以查看、修改、删除所有反馈

---

## 前端页面

### 用户端
- 入口: 个人中心页面增加"意见反馈"按钮
- 页面: 反馈提交表单 + 我的反馈列表

### 管理端
- 入口: 侧边栏新增"反馈管理"菜单
- 页面: 反馈列表（可筛选状态）+ 详情查看
