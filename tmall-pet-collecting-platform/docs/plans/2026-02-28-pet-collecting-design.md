# 天猫宠物用品数据采集系统改造设计

**项目**: 天猫潮玩电商数据采集系统 → 天猫宠物用品数据采集系统
**日期**: 2026-02-28
**状态**: 已批准

---

## 1. 改造概述

将现有的天猫潮玩数据采集系统改造为天猫宠物用品数据采集系统，保持技术架构不变，更换数据类目并扩展宠物特有的分析维度。

### 1.1 改造范围

| 模块 | 改造内容 |
|------|----------|
| 数据清理 | 清除现有潮玩数据，重新采集宠物用品数据 |
| 数据模型 | 新增宠物类型、用途分类字段 |
| 爬虫模块 | 复用现有爬虫，更换关键词配置 |
| 统计分析 | 新增按宠物类型、用途等维度分析 |
| 前端UI | 更新标签、筛选器和统计卡片 |

## 2. 数据模型设计

### 2.1 Product 模型扩展

新增字段：

```python
class Product(models.Model):
    # ... 现有字段保持不变 ...

    # 新增字段
    PET_TYPE_CHOICES = [
        ('cat', '猫咪'),
        ('dog', '狗狗'),
        ('aquatic', '水族'),
        ('small_pet', '小宠物'),
        ('other', '其他'),
    ]
    PET_USE_CHOICES = [
        ('food', '食品'),
        ('supplies', '用品'),
        ('toy', '玩具'),
        ('healthcare', '医疗保健'),
        ('grooming', '清洁护理'),
    ]

    pet_type = models.CharField(max_length=20, choices=PET_TYPE_CHOICES, null=True, blank=True, verbose_name='宠物类型')
    pet_use = models.CharField(max_length=20, choices=PET_USE_CHOICES, null=True, blank=True, verbose_name='用途分类')
```
