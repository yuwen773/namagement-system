# 校园智慧后勤能耗监测可视化系统 - 产品需求文档 (PRD)

## 1. 文档概述
### 1.1 项目背景
随着高校规模的扩大，校园水、电、燃气等能源消耗日益增长。为了实现校园能耗的精细化管理和节能减排，本项目旨在构建一个基于ECharts的校园智慧后勤能耗监测可视化系统。该系统将基于现有的**校园能耗数据集**，利用大数据处理技术（Spark）和数据库存储架构（MySQL），通过Vue.js和ECharts为管理员和普通用户提供直观的能耗监测与分析服务。

### 1.2 项目目标
- **数据导入**：支持从CSV/Excel等数据集中批量导入水、电、气等多源异构能耗数据。
- **数据存储**：利用MySQL存储海量历史能耗数据与业务数据。
- **智能分析**：基于Spark进行多维度分析、异常识别和趋势预测。
- **可视化展示**：提供大屏监控和多端交互界面，提升管理效率。

| 角色 | 描述 | 主要职责 |

## 3. 功能需求 - 管理端 (Admin Portal)
**预计页面数量：7页**

### 3.1 综合监控大屏 (Dashboard)
- **功能描述**：系统首页，以可视化大屏形式展示校园整体能耗概况（基于数据集的最新状态）。
- **核心模块**：
  - **关键指标卡片**：总能耗（水/电/气）、平均功率、累计能耗、数据覆盖率。
  - **告警概览**：显示数据集中识别出的能耗超标或异常记录。
  - **能耗趋势图**：全校能耗随时间变化的曲线（ECharts折线图）。
  - **能耗分布饼图**：各区域（教学区/生活区/办公区）或各能源类型的占比。
  - **地图/3D模型**：校园地图展示各楼宇能耗热力分布。

### 3.2 监测中心 (Monitoring Center)
- **功能描述**：对具体楼宇、楼层或设备的能耗数据进行详细查看。
- **核心模块**：
  - **区域导航树**：按“校区-楼宇-楼层-房间”层级选择监测点。
  - **数据看板**：展示选中节点的电压、电流、功率、水流速等详细参数（最新导入数据）。
  - **动态曲线**：支持选择特定参数查看分钟级/小时级的变化趋势。

### 3.3 统计分析报表 (Data Analysis)
- **功能描述**：提供历史数据的多维度查询与分析，支持导出报表。
- **核心模块**：
  - **历史查询**：按日、月、年或自定义时间段查询能耗数据。
  - **同比/环比分析**：对比去年同期或上月同期的能耗差异（ECharts柱状图/混合图）。
  - **能耗排名**：各楼宇或部门的能耗Top10排行榜。
  - **报表导出**：支持Excel/PDF格式导出分析结果。

### 3.4 异常告警管理 (Alarm Management)
- **功能描述**：基于规则分析数据集中的异常并展示。
- **核心模块**：
  - **异常记录**：列表展示数据分析出的异常（如：持续高负荷、突变异常）。
  - **历史告警**：查询历史异常记录。
  - **规则配置**：设置分析阈值（如：日用电量>100kWh）。

### 3.5 设备资产管理 (Device Management)
- **功能描述**：维护虚拟设备台账以关联数据集中的设备ID。
- **核心模块**：
  - **设备台账**：设备列表（设备ID、型号、安装位置）。
  - **数据状态**：查看设备是否有数据记录。
  - **设备维护**：添加、编辑、删除设备信息。

### 3.6 基础档案配置 (Energy Configuration)
- **功能描述**：配置建筑结构和能源计费标准。
- **核心模块**：
  - **建筑档案**：维护校园建筑层级结构（楼宇、房间信息）。
  - **能源类型**：定义水、电、气等能源分类及单位。
  - **费率设置**：设置分时电价、阶梯水价等计费规则。

### 3.7 系统管理 (System Settings)
- **功能描述**：用户权限与系统日志管理。
- **核心模块**：
  - **用户管理**：管理员与普通用户的账号创建、编辑、重置密码。
  - **角色权限**：分配不同角色的菜单访问权限。
  - **操作日志**：记录系统的关键操作行为（登录、数据导入等）。

## 4. 功能需求 - 用户端 (User Portal)
**预计页面数量：6页**

### 4.1 个人/部门首页 (User Dashboard)
- **功能描述**：用户登录后的概览页面，关注自身相关的能耗。
- **核心模块**：
  - **当前状态**：当前房间/部门的最近一次记录的功率/流量，累计用量。
  - **余额/预算**：显示剩余电费/水费余额（如适用）或本月预算使用进度。
  - **简报**：用能总结及节能建议。

### 4.2 用能查询明细 (Usage History)
- **功能描述**：查询详细的历史用能记录。
- **核心模块**：
  - **日历视图/列表视图**：查看每日能耗详情。
  - **趋势图表**：展示本周/本月的用能趋势折线图。
  - **时段分析**：查看高峰、平峰、谷峰时段的用能分布。

### 4.3 费用与充值 (Cost & Payment)
- **功能描述**：查看费用账单，支持模拟充值。
- **核心模块**：
  - **我的账单**：按月生成的费用账单明细。
  - **充值记录**：历史缴费记录查询。
  - **模拟计算器**：输入用量估算费用。

### 4.4 能耗对比与排名 (Comparison & Ranking)
- **功能描述**：通过横向对比提升节能意识（Gamification）。
- **核心模块**：
  - **同类对比**：展示本宿舍/部门与全校平均水平的对比雷达图。
  - **节能排名**：在同类用户群组中的节能排名（如：全校宿舍节能Top榜）。

### 4.5 节能公告与知识 (Tips & Notices)
- **功能描述**：接收学校后勤的通知和学习节能知识。
- **核心模块**：
  - **通知公告**：停水停电通知、系统维护通知。
  - **节能百科**：节能小贴士、政策法规宣传。

### 4.6 个人中心 (Profile)
- **功能描述**：维护个人信息及偏好。
- **核心模块**：
  - **基本资料**：修改头像、联系方式。
  - **账号绑定**：绑定具体的房间或部门（支持多房间绑定）。
  - **告警订阅**：开启或关闭余额不足提醒、异常用能提醒。

## 5. 非功能性需求
### 5.1 性能需求
- **导入效率**：支持百万级数据记录的快速导入与解析。
- **查询响应**：复杂统计分析查询响应时间<3秒。
- **数据处理**：Spark处理大规模数据集的清洗与聚合，延迟分钟级。

### 5.2 安全需求
- **数据安全**：所有敏感数据（如用户密码）加密存储。
- **访问控制**：基于RBAC（Role-Based Access Control）的权限管理模型。

### 5.3 扩展性与兼容性
- **数据兼容**：支持多种格式的数据集导入（CSV, Excel, JSON）。
- **浏览器兼容**：支持主流浏览器（Chrome, Firefox, Edge）。

---

## 6. 技术架构
### 6.1 技术栈
- **前端**：Vue 3, Element Plus, ECharts, Tailwind CSS
- **后端**：Django 5.2, Django REST Framework
- **大数据处理**：Apache Spark (离线分析)
- **数据库**：MySQL
- **数据导入**：Pandas / Python Scripts

### 6.2 数据流向
1. **数据源**：能耗数据集文件 (CSV/Excel)。
2. **导入层**：Python脚本/管理端上传 -> 数据清洗服务 -> MySQL。
3. **处理层**：
   - 离线分析：Spark -> 数据聚合/异常检测 -> MySQL (统计报表)。
4. **应用层**：Vue.js前端调用API -> ECharts渲染图表。
