# 技术栈说明文档 (Tech Stack)

本文档详细描述了“天猫潮玩电商数据采集系统”所采用的技术选型与架构方案。

## 1. 技术架构概览

本项目采用前后端分离架构：
*   **前端**：基于 Vue 3 构建单页面应用 (SPA)，负责页面展示、交互逻辑与数据可视化。
*   **后端**：基于 Django 5.2 提供 RESTful API，处理业务逻辑、数据存储与爬虫调度。
*   **数据层**：MySQL 存储结构化商品数据与用户信息。

---

## 2. 前端技术栈 (Frontend)

| 技术项 | 名称/版本 | 选型理由与用途 |
| :--- | :--- | :--- |
| **核心框架** | **Vue 3** (Composition API) | 现代化的渐进式 JavaScript 框架，提供更好的性能与代码组织方式（通过 Composition API）。 |
| **UI 组件库** | **Element Plus** | 基于 Vue 3 的企业级组件库，用于快速构建管理后台界面（表格、表单、按钮等）。 |
| **可视化库** | **ECharts 5** | 百度开源的强大图表库，用于实现价格分布饼图、销量排行柱状图等核心可视化需求。 |
| **样式工具** | **Tailwind CSS** | 原子化 CSS 框架，无需编写大量 CSS 文件，快速构建响应式与定制化布局。 |
| **HTTP 客户端** | **Axios** | 轻量级 HTTP 库，用于与后端 REST API 进行数据交互。 |
| **路由管理** | **Vue Router 4** | 管理单页面应用的路由跳转（如从仪表盘跳转至商品详情页）。 |
| **状态管理** | **Pinia** | Vue 3 推荐的状态管理库，用于管理用户登录状态、全局配置等。 |

---

## 3. 后端技术栈 (Backend)

| 技术项 | 名称/版本 | 选型理由与用途 |
| :--- | :--- | :--- |
| **Web 框架** | **Django 5.2** | Python 高级 Web 框架，内置强大的 ORM、认证系统与管理后台，适合快速开发企业级应用。 |
| **API 框架** | **Django REST Framework (DRF)** | 基于 Django 的 API 构建工具，用于生成标准化的 JSON 接口，供前端调用。 |
| **数据库** | **MySQL 8.0+** | 成熟的关系型数据库，支持千万级数据存储，满足本项目“不少于 10,000 条数据”的存储需求。 |
| **数据处理** | **Pandas** | Python 数据分析库，用于爬取数据的清洗（去重、缺失值处理）与格式化。 |
| **异步/定时** | **Celery** (可选) / **APScheduler** | 用于异步执行耗时的爬虫任务，避免阻塞 HTTP 请求线程。 |

---

## 4. 数据采集技术 (Crawler)

| 技术项 | 名称 | 用途 |
| :--- | :--- | :--- |
| **浏览器自动化** | **Selenium** / **Playwright** | 模拟真实用户浏览器操作，解决天猫复杂的动态加载与反爬验证（演示模式采集）。 |
| **HTTP 请求** | **Requests** | 配合 Cookie 池进行轻量级的数据抓取（如 API 逆向接口调用）。 |
| **HTML 解析** | **BeautifulSoup4** / **lxml** | 从网页 HTML 源码中提取商品标题、价格、销量等关键信息。 |
