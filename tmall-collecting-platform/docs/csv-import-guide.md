# CSV数据导入使用指南

## 功能特性

- ✅ **批量导入**：自动导入目录下所有CSV文件
- ✅ **智能清洗**：自动检测表头、填充缺失字段、截断超长内容
- ✅ **多编码支持**：UTF-8、GBK、GB2312
- ✅ **容错机制**：跳过空行和无效数据
- ✅ **进度追踪**：实时显示导入状态

## CSV文件格式

### 标准表头

```csv
商品ID,商品标题,价格,价格单位,价格描述,卖家昵称,店铺名称,店铺标签,销量,地区,标签,商品属性,图片链接,商品链接
```

### 字段说明

| 字段 | 必填 | 说明 | 示例 |
|------|:----:|------|------|
| 商品ID | - | 天猫商品ID | 750776311357 |
| 商品标题 | ⚠️ | 自动生成 | 万代PG独角兽高达 |
| 价格 | ✅ | 商品价格 | 3599 |
| 店铺名称 | ⚠️ | 自动生成 | 永乐玩具 |
| 商品链接 | ⚠️ | 自动生成 | http://detail.tmall.com/... |
| 销量 | - | 支持"人付款"格式 | 65人付款 |
| 商品属性 | - | 用\|分隔 | 出售状态:现货\|品牌:Bandai |

⚠️ = 自动填充，为空时会智能生成

## 使用方法

### 方法一：Django命令（推荐）

```bash
cd backend

# 导入所有CSV
python manage.py import_csv

# 指定目录
python manage.py import_csv --dir /path/to/csv

# 试运行
python manage.py import_csv --dry-run
```

### 方法二：Python脚本

```bash
cd backend
python run_import.py
```

### 方法三：Web API

```http
POST /api/products/import/
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "data_dir": "/path/to/csv"
}
```

## 数据清洗规则

1. **表头检测**：自动识别缺失表头的CSV并添加标准表头
2. **字段填充**：
   - 标题缺失 → 从属性/ID组合生成
   - 店铺缺失 → 使用卖家昵称或默认值
   - 链接缺失 → 根据商品ID生成
3. **字段截断**：
   - URL：1000字符
   - 标题：500字符
   - 店铺：200字符
4. **数据解析**：
   - 销量："2000+人付款" → 2000
   - 属性："状态:现货\|品牌:Bandai" → JSON
5. **允许重复**：相同商品ID可存在多条记录

## 注意事项

1. **文件位置**：默认读取 `backend/data/` 目录
2. **编码问题**：工具自动尝试多种编码
3. **批次管理**：每次导入生成独立批次号
4. **权限要求**：Web API仅管理员可用

## 故障排查

### 找不到CSV文件
```
解决：将文件放到 backend/data/ 目录或使用 --dir 参数
```

### 编码错误
```
解决：工具已自动处理，如仍失败请转换为UTF-8
```

### 跳过记录较多
```
解决：检查必填字段（价格、标题）是否为空行
```
