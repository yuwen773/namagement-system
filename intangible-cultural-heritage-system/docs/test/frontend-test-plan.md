# 前端功能测试计划

## 测试前准备

### 环境要求
- **后端服务**: `http://127.0.0.1:8000`
- **前端服务**: `http://localhost:5173`
- **数据库**: MySQL 3306, `heritage_db`

### 启动服务
```bash
# 后端
cd backend
python manage.py runserver

# 前端
cd frontend
npm run dev
```
