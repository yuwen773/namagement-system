### 常见问题排查

#### 1. 登录失败
- 检查后端是否运行
- 检查数据库中是否有测试用户
- 查看浏览器控制台错误信息

#### 2. 图表不显示
- 检查后端 API 是否返回数据
- 打开浏览器控制台查看网络请求
- 检查是否有 JavaScript 错误

#### 3. 401 错误
- Token 可能已过期，重新登录
- 检查 localStorage 中是否有 access_token

#### 4. 图表显示异常
- 刷新页面
- 检查浏览器控制台是否有 ECharts 错误
- 确认数据格式正确

## 技术说明

### 文件结构
```
frontend/src/
├── layouts/
│   └── MainLayout.vue          # 主布局组件
├── views/
│   ├── Login.vue               # 登录页面
│   └── Dashboard.vue           # 驾驶舱页面
├── components/
│   └── StatCard.vue            # 统计卡片组件
├── api/
│   ├── auth.ts                 # 认证 API
│   ├── dashboard.ts            # 驾驶舱 API
│   └── category.ts             # 分类 API
├── stores/
│   └── user.ts                 # 用户状态管理
├── router/
│   └── index.ts                # 路由配置
└── utils/
    └── request.ts              # Axios 拦截器
```

### 设计特点
- **主题色**：棕色系（#8b4513, #a0522d）符合文化遗产主题
- **动画**：数字滚动、页面切换淡入淡出、悬停效果
- **响应式**：Grid 布局自动适配
- **内存管理**：ECharts 图表正确 dispose

### API 端点
- `POST /api/v1/auth/login/` - 登录
- `POST /api/v1/auth/logout/` - 登出
- `GET /api/v1/dashboard/overview/` - 总览统计
- `GET /api/v1/dashboard/map-distribution/` - 地图分布
- `GET /api/v1/dashboard/category-distribution/` - 类别占比
- `GET /api/v1/dashboard/country-ranking/` - 国家排行
- `GET /api/v1/categories/` - 分类列表
