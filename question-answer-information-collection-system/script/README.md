  新增功能：
  ┌─────────────────────────────┬────────────────────────────────────────────────────────┐
  │            方法             │                          说明                          │
  ├─────────────────────────────┼────────────────────────────────────────────────────────┤
  │ get_question_ids_from_csv() │ 从 CSV 文件读取问题 ID 列表                            │
  ├─────────────────────────────┼────────────────────────────────────────────────────────┤
  │ get_detail_page()           │ 获取指定问题 ID 的详情页 HTML                          │
  ├─────────────────────────────┼────────────────────────────────────────────────────────┤
  │ parse_detail()              │ 解析问题详情页，提取标题、问题内容、最佳答案、所有答案 │
  ├─────────────────────────────┼────────────────────────────────────────────────────────┤
  │ crawl_details()             │ 批量爬取问题详情，支持分批、进度显示                   │
  ├─────────────────────────────┼────────────────────────────────────────────────────────┤
  │ _save_results()             │ 保存结果到 CSV 和 JSON 文件                            │
  └─────────────────────────────┴────────────────────────────────────────────────────────┘
  使用方法：

  from crawler import QihuWendaDetailCrawler

  crawler = QihuWendaDetailCrawler(delay=1.0)

  # 1. 从CSV读取问题ID
  ids = crawler.get_question_ids_from_csv("360_qa.csv")

  # 2. 批量爬取详情
  details = crawler.crawl_details(
      ids,
      start_idx=0,      # 起始索引
      max_count=10,     # 最大爬取数量，None表示全部
      show_progress=True
  )

  命令行使用：

  # 爬取前10条问题的详情
  python crawler.py detail 360_qa.csv 0 10

  # 从第5条开始，爬取20条
  python crawler.py detail 360_qa.csv 5 20

  输出文件：
  - 360_qa_detail.csv - 包含 id、标题、问题内容、最佳答案
  - 360_qa_detail.json - 完整 JSON 数据，包含所有答案详情
