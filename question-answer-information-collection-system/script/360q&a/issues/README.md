## 问题修复记录

### 问题：爬虫在第6页停止，但实际有数据

**发现时间：** 2026-02-09

**问题描述：**
原始爬虫在爬取第5页后，第6页判定为"无数据"并停止。但实际访问第6页有15条问题数据。

**原因分析：**
1. 原始空页判断仅依赖 `parse_question_list()` 返回的列表是否为空
2. 如果解析失败或解析逻辑有bug，会误判为空页
3. 没有多维度验证页面是否真的为空

**解决方案：**
1. 新增 `_is_empty_page()` 方法，使用多种方式检测：
   - 检查 `ul.question-list li` 选择器
   - 检查 `li[data-askid]` 属性
   - 检查 `/q/` 链接
   - 检查 `.pagination` 分页元素

2. 改进 `crawl_pages()` 方法：
   - 区分"解析失败"和"确实为空"
   - 添加连续空页检测机制
   - 记录累计爬取数量

**验证结果：**
- 第6页HTML长度：29496字符
- 空页检测：否
- 解析问题数：15条
- 前3条问题示例：
  1. 这些惊险的出差经历险到让人窒息...
  2. 山西大同的悬空寺建造得那么高是怎么做到的...
  3. 山西晋中祁县的各类醋品牌有哪些...

**调试命令：**
```bash
python crawler.py 6  # 调试第6页
```
