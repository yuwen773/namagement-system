# 管理端筛选功能设计方案

## 概述

为问答信息采集系统的管理端三个列表页面（用户管理、公告管理、数据中心）添加高级筛选查询功能，并同步修改后端 API 支持这些筛选参数。

## 现有问题

1. **用户管理** - 只有关键字搜索，无分页、无角色/状态筛选
2. **公告管理** - 无分页、无筛选，管理员只能看到启用状态
3. **数据中心** - 只有关键字搜索和基础分页，缺少分类/地理位置/时间范围等筛选

---

## API 筛选参数设计

### 1. 用户管理 API (`/api/auth/users/`)

| 参数 | 类型 | 说明 |
|------|------|------|
| `page` | int | 页码，默认1 |
| `page_size` | int | 每页数量，默认20，最大100 |
| `search` | string | 用户名关键字搜索 |
| `role` | string | 角色筛选 (`admin` / `user`) |
| `is_active` | bool | 状态筛选 (`true` / `false`) |
| `created_at_after` | datetime | 创建时间起始 |
| `created_at_before` | datetime | 创建时间结束 |
| `ordering` | string | 排序 (`created_at`, `-created_at`, `username`, `-username`) |

### 2. 公告管理 API (`/api/notices/`)

| 参数 | 类型 | 说明 |
|------|------|------|
| `page` | int | 页码，默认1 |
| `page_size` | int | 每页数量，默认20，最大100 |
| `search` | string | 标题关键字搜索 |
| `is_active` | bool | 状态筛选 (`true` / `false`) |
| `created_at_after` | datetime | 创建时间起始 |
| `created_at_before` | datetime | 创建时间结束 |
| `ordering` | string | 排序 (`created_at`, `-created_at`, `title`) |

**修复：** 管理员可查看全部公告，非管理员只看启用公告

### 3. 数据中心 API (`/api/questions/`)

| 参数 | 类型 | 说明 |
|------|------|------|
| `page` | int | 页码，默认1 |
| `page_size` | int | 每页数量，默认20，最大100 |
| `search` | string | 标题关键字搜索 |
| `category` | string | 分类精确筛选 |
| `location` | string | 地理位置筛选 |
| `publish_time_after` | date | 发布时间起始 |
| `publish_time_before` | date | 发布时间结束 |
| `answer_count_min` | int | 最小回答数量 |
| `answer_count_max` | int | 最大回答数量 |
| `ordering` | string | 排序 (`created_at`, `-created_at`, `publish_time`, `-publish_time`, `answer_count`, `-answer_count`) |

## 前端筛选组件设计

### 用户管理页面

```
┌────────────────────────────────────────────────────────────────────────┐
│ [搜索用户名...]  │ [角色: 全部▼] [状态: 全部▼]        │ [刷新] [添加用户] │
└────────────────────────────────────────────────────────────────────────┘
```

筛选选项：
- 角色：全部 / 管理员 / 普通用户
- 状态：全部 / 正常 / 禁用

### 公告管理页面

```
┌────────────────────────────────────────────────────────────────────────┐
│ [搜索公告标题...] │ [状态: 全部▼] [时间范围: ▼]      │ [刷新] [添加公告] │
└────────────────────────────────────────────────────────────────────────┘
```

筛选选项：
- 状态：全部 / 启用 / 禁用
- 时间范围：日期范围选择器

### 数据中心页面

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│ [搜索问答标题...] │ [分类: 全部▼] [位置: 全部▼] [回答数: ▼] │ [刷新]          │
│                   [发布时间: ▼]                                                        │
└──────────────────────────────────────────────────────────────────────────────────┘
```

筛选选项：
- 分类：下拉选择（从 API 获取可选分类列表）
- 位置：下拉选择（从 API 获取可选位置列表）
- 回答数：全部 / 0 / 1-3 / 3以上
- 发布时间：日期范围选择器

## 实现步骤

### 后端
1. 修改用户管理 API - 添加分页和筛选参数
2. 修改公告管理 API - 添加分页和筛选参数，修复管理员查看权限
3. 修改数据中心 API - 添加分类/位置/时间/回答数量筛选参数

### 前端
1. 用户管理页面 - 添加角色/状态下拉筛选
2. 公告管理页面 - 添加状态/时间范围筛选
3. 数据中心页面 - 添加分类/位置/回答数/发布时间筛选

---

## 验收标准

1. 三个页面都能通过下拉选择器进行筛选
2. 筛选后自动更新列表，支持分页
3. 筛选条件可重置
4. 后端 API 正确返回筛选结果
5. UI 风格与现有页面保持一致
